# Holdline

Flipper roguelite : défends ta ligne contre des hordes sur une table géante que tu construis entre les vagues.

Ouvrir `index.html` dans un navigateur suffit pour jouer.

## Commandes

| Action | PC | Mobile |
|---|---|---|
| Flippers gauches | ← / Q / A / Maj gauche | Moitié gauche de l'écran |
| Flippers droits | → / D / P / Maj droite | Moitié droite de l'écran |
| Lanceur | Maintenir Espace ou ↓ | Maintenir l'écran |
| Secouer la table | N | — |
